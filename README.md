# 🛠️ PDF 极客精密工具箱 (PDF Tools Suite)

PDF 极客精密工具箱是一个 100% 运行在客户端、注重绝对隐私保护的安全 PDF 工具合集。

本项目在根目录包含一个统一的入口导航门户，融合了三个子项目的 UI/UX 风格，支持自动主题同步与中英文多语言切换。

## 📁 包含的项目

本项目由以下三个纯前端、零上传的高性能 PDF 效率工具组成：

1. **📄 [PDFSCN](./PDFSCN/) (部署域名: [scn.9ump.com](https://scn.9ump.com)) - PDF 扫描件模拟器**
   - 能够将电子版 PDF 转换成逼真的纸质扫描件效果。
   - 支持多级旋转偏角、对比度、噪点和模糊度微调，还原真实纸张质感。
2. **🖨️ [PDFPRN](./PDFPRN/) (部署域名: [prn.9ump.com](https://prn.9ump.com)) - PDF 打印机模拟器**
   - 模拟真实物理打印机的缺陷与特质（如激光高清、家用喷墨、省粉草稿、针式票据）。
   - 具备抖动抖落、鼓轮条纹波和彩虹套色边缘重影，支持 Web Worker 并行渲染。
3. **📐 [PDFQFZ](./PDFQFZ/) (部署域名: [qfz.9ump.com](https://qfz.9ump.com)) - PDF 骑缝章与印章工具**
   - 专为公文处理设计，智能对印章进行多页分割拼接加盖骑缝章（支持上下左右四向）。
   - 完美还原正片叠底（Multiply）色彩物理叠加，支持单页多处自由落章与多文件批量处理。

---

## ⚡ 项目核心特色

- 🛡️ **绝对隐私保障**：所有 PDF 文件的解析、处理、混合和生成，均 **100% 完全在您的本地浏览器内运行**，没有任何服务器上传逻辑，从物理上杜绝机密信息泄漏。
- 🌓 **跨项目主题同步**：支持浅色/深色/跟随系统模式。在入口门户切换主题后，选择将自动同步至 `localStorage`，点击进入子项目时会无缝呈现您选择的主题。
- 🌍 **无缝多语言支持**：内置极简的中英文切换，一键转换整个页面语言。
- 📱 **适配多种设备**：纯 Vanilla CSS 配合精细设计变量，完美适配从移动端到 Retina 大屏的响应式体验。

## 🧑‍💻 本地开发与部署

此根目录项目为一个纯静态网页（HTML, CSS, JS），您只需双击 `index.html` 即可在本地浏览器中运行，也可以使用任何静态文件服务器将其托管（例如 Nginx, Vercel, Github Pages, Cloudflare Pages 等）。

### 启动本地开发服务 (推荐)

如果您希望在开发过程中有更流畅的调试体验，可以使用 `serve` 或 `http-server` 快速起一个本地服务器：

```bash
# 使用 npx 启动轻量静态服务器
npx http-server ./
```

打开浏览器访问输出的 `http://localhost:8080/` 即可。
